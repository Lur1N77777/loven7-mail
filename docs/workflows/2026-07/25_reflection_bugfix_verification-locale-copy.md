### 主要变更

- 仅在强验证码上下文、同一行标签或结构化高亮中接受候选。
- 排除 `GPT-6` 一类产品版本、州名/邮编、地址、日期时间、HTML entity 和链接查询参数。
- 保留 Notion 风格混合大小写字母码，并去除相邻模板噪声数字。
- 强标签空白不再跨越换行；跨行宽松候选仅允许验证码出现在行首。
- 普通 TitleCase 英文词不再作为纯字母验证码。
- 切换语言只更新展示文案和运行时语言，不重新请求账号设置或邮件列表。
- HTML 模板造成的连续空白行不再消耗跨行扫描额度；只计入最多两个非空候选行。
- Admin 列表/详情缓存升级为 v6，Webmail 邮件缓存升级为 v3；详情会话缓存跟随解析器缓存版本，避免旧识别结果覆盖新列表结果。

## 3. 遇到的错误

1. **强标签正则跨行捕获（重要）**：`verification code` 标题后的 `Received, thanks.` 被识别为字母验证码。
2. **跨行候选位置过宽（重要）**：回复正文中的普通数字可以被上一行验证码标题提升为候选。
3. **发布门禁夹具域名错误（次要）**：测试使用真实 Notion 域名，触发项目的公开发布隐私检查。
4. **HTML-only 邮件空白行漏识别（重要）**：ChatGPT 模板将提示语和验证码放在不同段落，标签与条件注释产生的空白行耗尽了扫描额度。
5. **详情会话缓存未版本化（重要）**：旧详情缓存可能在打开邮件时覆盖新解析出的验证码。

## 4. 根本原因分析

### 为什么会出现这个错误?

- 强标签正则使用 `\s*`，其语义包含换行，导致标签和候选越过邮件标题/正文边界。
- 下一行扫描使用 `find` 搜索任意位置的数字，没有要求验证码位于行首或由本行标签直接引导。
- 纯字母候选只检查混合大小写，未排除常见的首字母大写自然词。
- 语言值进入 `useMemo`/`useCallback` 依赖后，引发 API client 和邮件工作区请求链重新创建。
- 跨行扫描按物理行而不是非空语义行计数，没有考虑真实营销邮件 HTML 中大量格式空白和 Outlook 条件注释。
- 列表缓存升级了版本，但邮件详情的 `sessionStorage` key 没有绑定同一解析器版本。

### 是什么导致编写时出现这个错误?

- 早期逻辑以提高召回率为主，缺少“回复邮件标题仍含验证码关键词”的负样本。
- Admin 与 Webmail 曾各自维护识别器，边界规则和缓存行为不一致。
- 测试覆盖了地址和产品版本，但没有覆盖标题与下一行自然语言之间的边界。
- 最初的 ChatGPT 回归样例使用紧凑纯文本，没有使用正式邮件的 HTML-only MIME 结构。
- 发布夹具直接复用了真实 URL，没有先遵循仓库的 `example.test` 公开测试约定。

## 6. 经验总结

### 核心洞察

- 邮件标题与正文是不同语义区，正则中的通用空白不能无意跨越这个边界。
- 验证码识别应优先精度：纯字母码、跨行数字和 HTML 源码都必须要求额外强证据。
- 语言切换属于纯 UI 状态，不应进入网络身份、API client 或数据加载回调的依赖图。
- 复制体验不仅要显示正确，还要确保剪贴板只收到清洗后的单个验证码。

### 预防策略

- 每次提高召回率时同时添加标题回复、地址、日期、产品版本和自然语言负样本。
- 双端共用同一个纯函数识别器，并通过缓存版本升级淘汰历史错误结果。
- 邮件解析缓存必须整体版本化，列表缓存和详情缓存不能只升级其中一处。
- 网络回调需要语言文案时，在错误发生时读取运行时语言，避免以语言 state 重建回调。
- 所有公开测试 URL 使用 `example.test`，发布前始终运行完整 `check:release`。

### 识别的最佳实践

- 先构造失败测试并确认红灯，再做单一最小修复。
- 将 HTML 属性与可见文本分离，禁止从 `href` 查询参数提取验证码。
- 对候选进行结构校验、上下文评分、去重和数字前缀噪声消除。
- 浏览器验证同时检查文案、选中邮件、搜索词、滚动状态和新增网络请求。

## 7. 知识提炼

### 可复用模式

- “可见文本归一化 → 强上下文候选 → 结构校验 → 评分去重”的高精度信息提取模式。
- “运行时语言 ref/模块状态供异步回调读取，React state 仅驱动展示”的无副作用本地化模式。
- “Clipboard API → textarea/`execCommand` 回退 → 恢复焦点”的兼容复制模式。

### 应避免的反模式

- 用 `\s` 连接来自不同语义行的标签和候选。
- 在验证码标题后的任意位置搜索第一个数字。
- 从原始 MIME、HTML 属性或链接查询参数无条件提取短字符串。
- 为了错误提示文案，把 locale 放进会触发请求的 callback 依赖。
